## 内容

| 路径 | 内容 | 对应正文 |
|---|---|---|
| `docs/appendices.md` | 附录A—J 完整正文：关系基础分类、合同目录、证据行、材料索引、条件预测细节、目录来源（A—F）；盲区定理完整证明（G）；五状态多路径模型（H）；应用例K1 检查清单（I）；MOC 尺度／叠加／源核对照（J） | 附录A—F 要点、附录G、§4.7.2、§4.8.2、§4.8.3 |

## 边界

- 本仓库暂不含 ONIX／OpenMOC 源码、CRAM 系数文件与端记录输出。`EXPECTED.md` 列出需索取的完整数据包。
- `docs/appendices.md` 与 `records/` 是同一批保存读数的记录副本，不构成新实验、新识别数量或新覆盖证据。
- 材料复核、证书重生、原环境重建与运行身份认证是不同层级，完成范围见附录D.3。
- 历史评审归档不收录。第三方代码按各自许可使用，核数据按各自许可。
