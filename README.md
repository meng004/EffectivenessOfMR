# EffectivenessOfMR

《方程结构蜕变关系的离散后有效性预测：条件、方法与验证边界》的补充材料：附录完整正文与被正文压缩的实验记录。

## 内容

| 路径 | 内容 | 对应正文 |
|---|---|---|
| `docs/appendices.md` | 附录A—J 完整正文：关系基础分类、合同目录、证据行、材料索引、条件预测细节、目录来源（A—F）；盲区定理完整证明（G）；五状态多路径模型（H）；应用例K1 检查清单（I）；MOC 尺度／叠加／源核对照（J） | 附录A—F 要点、附录G、§4.7.2、§4.8.2、§4.8.3 |
| `records/` | 各版本的静态核验脚本、迁移与清单 JSON、上游裁定记录 | — |

正文只保留定理陈述与关键读数；完整正文、证明与原始实验记录都在 `docs/appendices.md` 与 `records/`。

## 边界

- 本仓库不含 ONIX／OpenMOC 源码、CRAM 系数文件与运行输出。正文所称的代码、数据与实验回放尚未在本仓库提供，可获取范围以本文件为准。
- `docs/appendices.md` 与 `records/` 是同一批保存读数的记录副本，不构成新实验、新识别数量或新覆盖证据。
- 材料复核、证书重生、原环境重建与运行身份认证是不同层级，完成范围见附录D.3。
- 第三方代码按各自许可使用，核数据按各自许可。
