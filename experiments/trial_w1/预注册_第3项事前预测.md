# 预注册：第 3 项 5 条 MR 对两层句法变异体的事前预测

冻结日期：2026-11-10。冻结方式：本文件随 git 提交推送，提交时间戳早于任何变异运行结果。冻结后**不得修改**；如需修正，另起新文件说明修正内容与理由，原文件保留。

## 1. 预测对象

- 实验：[实验设计_第1与3项.md](实验设计_第1与3项.md) 第 3 项。
- 变异体：cosmic-ray 对 `openmc/deplete/{cram,chain,nuclide}.py` 生成、被测试执行到、运行正常结束的变异体。
- 判定：`run_mr.py` 的 5 条 MR，与 `run_oracle.py` 的独立参考预言。
- 预测在**变异体类别**层面作出，不针对单个变异体：作者此前未见过这批变异体，也未见过这 5 条 MR 在 OpenMC 源码变异上的结果。

## 2. 机制假设（预测依据）

方程 dN/dt = A·N，解 N(t) = exp(At)·N₀，由 CRAM 近似。变异只能破坏两样东西之一：

| 被破坏的对象 | 例子 | 仍然保持的性质 |
|---|---|---|
| 矩阵 A 的数值（组装错） | 衰变常数、分支比、目标核索引被改 | 求解器对 N₀ 仍线性 ⇒ MR1、MR2 必过；半群性对任意 A 都成立 ⇒ MR3 必过 |
| 求解映射本身（求解错） | CRAM 极点、留数、迭代、实部取值被改 | 只要映射仍是 N₀ 的线性函数，MR1、MR2 仍过 |

由此得到可检验的预测：**MR1–MR3 只对「破坏线性或改变时间依赖」的变异敏感；MR4（守恒）与 MR5（零块）才对矩阵组装错敏感。**

## 3. 预测（P1–P6）

记 K(X) 为 MR 集合 X 在该类可用变异体上的杀死率。

| 编号 | 预测 | 判为「成立」的条件 |
|---|---|---|
| P1 | 线性类 MR 对矩阵组装错近乎失明 | `chain.py`、`nuclide.py` 中 equation 层：K({MR1,MR2}) ≤ 0.10 |
| P2 | 结构类 MR 抓住大部分组装错 | 同上集合：K({MR4,MR5}) ≥ 0.50 |
| P3 | 方程项层比非方程项层更易被杀 | 全部文件：K(全部 MR)₍equation₎ − K(全部 MR)₍non_equation₎ ≥ 0.20 |
| P4 | 非方程项层的存活变异体多数不改变输出，而不是 MR 漏报 | non_equation 层存活变异体中，参考预言也判 pass 的比例 ≥ 0.70（即多数不改变输出） |
| P5 | 漏报集中在 equation 层的「同比缩放」类变异 | equation 层「MR 全过、参考预言判错」的变异体中，人工抽检 ≥ 半数是对 A 的整体或成比例改动（保持守恒与零块的改动） |
| P6 | 健康代码无误报 | 健康基线 3 次运行，5 条 MR 全部 pass（RTOL 不得放宽） |

## 4. 记账规则

- 每条预测的结果只能是「成立 / 不成立 / 未决」。「未决」仅限：该类可用变异体 < 10 个，或抽检无法判定。
- 报告全部 6 条，**未决不计入成功**；报告可判比例 n/6 与一致率。
- 一周可行性试验的通过判据（来自对专家评审的回应）：可判比例 ≥ 0.6，一致率 ≥ 0.7。
- P4、P5 依赖参考预言；若参考预言在健康代码上不过，P4、P5 记为未决。

## 5. 已知风险（事前声明）

- P1 的 0.10 阈值来自机制推理，没有数据校准；若变异让程序崩溃，`run_mr.py` 会把崩溃记为杀死，可能把 K({MR1,MR2}) 抬高。崩溃变异体按 `failed_mrs` 是否含 `crash` 单独计，**不计入 P1 分母**。
- 若按实验设计 §3.2 降级为手写矩阵，`chain.py` 不再被变异，P1、P2 改在 `nuclide.py` 上评估；若 `nuclide.py` 的 equation 层可用变异体也不足 10 个，则记为未决。
